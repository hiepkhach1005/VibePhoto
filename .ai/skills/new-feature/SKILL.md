# Implement a Feature

Use for each product-facing capability.

1. Identify the user story and acceptance criteria in `PRODUCT_REQUIREMENTS` or add them.
2. Map UI state, domain behavior, filesystem/persistence effects, errors, keyboard input, and accessibility.
3. Implement a complete vertical slice without mock production data.
4. Keep slow work off the main actor and make long work cancellable.
5. Add focused tests and manually exercise empty, loading, success, permission-denied, corrupt-input, and external-change states as applicable.
6. Update documentation and handoff.
