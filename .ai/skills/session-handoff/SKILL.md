# Session Handoff

Use before ending every implementation session.

1. Run the strongest available build and test commands.
2. Update `docs/CURRENT_STATUS.md` with objective facts only.
3. Append a dated entry to `docs/HISTORY.md`.
4. Mark completed tasks and add newly discovered work to `.ai/TASKS.md`.
5. Rewrite `.ai/SESSION_HANDOFF.md` with current objective, completed work, in-progress state, exact commands/results, decisions, key files, known issues, and numbered next steps.
6. Ensure a new agent can resume without relying on chat history.
